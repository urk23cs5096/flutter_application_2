# Ex. 2 – Adaptive and Responsive UI Design
24CS2016 – Building Applications using Flutter

E-Commerce Product Catalog using LayoutBuilder + GridView.builder and a reusable `ProductCard` widget.
Columns: 2 (< 600 px), 3 (< 900 px), 4 (>= 900 px).

## Run
1. `flutter create .`   (first time only, adds android/web/etc. folders)
2. `flutter pub get`
3. `flutter run -d chrome`
